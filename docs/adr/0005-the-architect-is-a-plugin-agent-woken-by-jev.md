# The architect is a plugin agent that Jev wakes

The architect lives in the Claude Code plugin, not in the CLI: an agent definition (`plugin/agents/architect.md`), a skill for onboarding and audits, and a hook (`plugin/hooks/architect.js`) that sends each plan, Edit and Write to `sessionkit hook architect-check` after it is done, without waiting. The Rust side only classifies: one Jev Choice over the change and `ARCHITECTURE.md` side by side, plus one Choice per decision record in `docs/adr/` in the same request, so each record is held against the change as a pair (a change that goes against one wakes the architect with its text), behind a `Classifier` trait so a command can answer instead. Advice is never a block: it is appended to the loop that made the change, and only a decision or drift asks the person. Its memory is `ARCHITECTURE.md` plus `docs/adr/`, the convention this repository and Matt Pocock's skills already use, and no state file: the baseline commit is the memory's first line. Reviews run as a second agent type registered at session start from the same file with read-only tools, because a plugin's hooks do not see the tool calls of an agent the plugin spawned itself (Claude Code 2.1.288 logs them as `skipped: re-entry`).
